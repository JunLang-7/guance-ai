# 设置填写说明（0.6.2）

这份说明讲两件事：**普通用户怎样用最少的步骤添加情报**，以及可选的 **WebDAV 跨设备同步**。

## 先看：普通用户不需要填任何密钥

请直接使用顶部「添加情报」（或市场情报页）。优先粘贴，不需要 AppID、AppSecret 或 Cookie；需要登录的页面可用内置登录窗口：

1. **公众号文章**：在微信里打开文章 → 右上角“···”→“复制链接” → 回到观策AI粘贴 → “读取并添加文章”。一次最多10篇公开文章；也可以上传包含公众号链接的 .txt/.csv 列表。
2. **抖音 / 小红书**：在平台点“分享”→“复制链接/复制文案” → 回到观策AI选择平台并保存。
3. **批量或固定来源**：用 CSV/JSON 导入，或在高级采集里使用 RSS/Atom、公开网页。
4. **需要登录的页面**：添加情报 →“登录窗口采集（实验）”，在独立窗口手动登录，打开视频/笔记/文章或搜索结果后点“采集当前页/搜索结果”。搜索页可缓慢加载，最多50条。

保存后会进入“市场情报”，标记为待核实，并尽量保留原文链接、标题和正文。粘贴模式不登录平台账号；登录窗口由你手动扫码/登录，应用不读取密码、不导出 Cookie、不绕过平台验证。

如果微信提示“环境异常/需要验证”，可以打开文章复制全文，用“抖音 / 小红书文案”入口保存；也可以在登录窗口中打开这篇文章后采集当前页面。

## 一、不需要 AppID / 密钥

设置里已经**不再提供 AppID/AppSecret 表单**。普通用户不需要申请开放平台应用，也不需要把账号密码、Cookie 或 token 填进应用。

需要登录的平台页面，请用「市场情报 → 添加情报 → 登录窗口采集（实验）」：

1. 打开登录窗口，由你本机扫码/登录。
2. 打开视频、笔记、文章或搜索结果。
3. 回到应用，点“采集当前页/搜索结果”。

应用只读取当前页面可见内容，不读取密码，也不导出 Cookie。公众号、小红书、抖音的官方 OAuth、关键词搜索和历史文章批量抓取仍未接入；未来接入时会做真正的授权登录，而不是让用户手填密钥。

## 二、WebDAV 跨设备同步

### 1. WebDAV 是什么

可以把 WebDAV 理解成“属于你的网络文件夹”。观策AI 把项目版本加密后放进这个文件夹，另一台电脑再读出来，实现跨设备同步。

它不是必填项。**不配置也能正常使用**，只是不能在两台电脑之间自动同步业务数据。

### 2. 最简单的做法：用坚果云

1. 登录[坚果云网页版](https://www.jianguoyun.com/)。
2. 打开「账户设置 → 安全选项 → 第三方应用管理」。
3. 点「添加应用」，名称填 `GuanceAI`，生成一个**应用密码**并复制。
4. 回到观策AI「设置 → 跨设备同步（WebDAV）」，按下表填写：

| 字段 | 填什么 |
|---|---|
| WebDAV 目录地址 | `https://dav.jianguoyun.com/dav/` |
| WebDAV 用户名 | 你的坚果云登录邮箱 |
| WebDAV 密码 | 第 3 步生成的**应用密码**，不是网页登录密码 |
| 独立同步口令 | 点“生成”，至少12位；保存到密码管理器 |

5. 点“保存并测试连接”。成功后点“立即同步”。
6. 应用会自动在目录里创建 `guance-v1` 专用子文件夹，**不用手动新建**。

第二台电脑填**完全相同的地址、用户名、应用密码和同步口令**，保存并测试后再同步。

### 3. 其他网盘

| 网盘 | 地址示例 | 用户名 | 密码 |
|---|---|---|---|
| Nextcloud | `https://你的服务器/remote.php/dav/files/你的用户名/` | Nextcloud 用户名 | 登录密码，推荐使用应用密码 |
| 群晖 NAS | `https://你的NAS地址:5006/共享文件夹名/` | DSM 用户名 | DSM 登录密码 |
| 其他 WebDAV | 服务商提供的 HTTPS 目录地址 | 服务商账号 | 服务商密码或应用密码 |

要点：

- 地址必须是 **HTTPS 目录**，并且你的账号有**写入权限**。
- 不要填网盘网页首页、分享链接、带 `?` 或 `#` 的地址。
- 群晖不要只填 NAS 根地址，建议填到某个共享文件夹。
- 地址末尾有没有 `/` 都可以，应用会自己处理。

### 4. 两台电脑怎么配

1. **第一台**：填写并保存，点“保存并测试连接”，再点“立即同步”。
2. **第二台**：填同一个地址、用户名、密码和同步口令，保存并测试，再同步。
3. 同步完成后，在第二台的项目列表里选择恢复出来的项目。
4. 两台电脑各自配置模型和平台凭据；这些凭据不会跨设备同步。
5. 可勾选“运行期间每分钟自动同步”；关闭应用后停止自动同步。

### 5. 常见错误

- **401 / 403 或“凭据或权限无效”**：用户名、密码或应用密码不对，或者账号没有该目录的写权限。
- **连接失败 / 404**：地址不是 WebDAV 目录，或少了路径；检查是否把网页地址当成了 WebDAV 地址。
- **“同步口令错误或密文损坏”**：两台设备的同步口令不一致，或口令输错。同步口令不是 WebDAV 密码。
- **目录里已有旧版数据**：0.6.1 及更早版本升级时，所有设备先升级，然后配置**同一个新的空目录**，旧目录保留。
- **换了网盘/账号/目录**：换站点或账号要重新填 WebDAV 密码；换目录要明确填同步口令（迁移时可填原口令）。
- **忘记同步口令**：首版无法在原目录轮换或找回口令。先导出项目备份，再用新的空目录和新的口令重新初始化。

### 6. 密码和口令有什么区别

- **WebDAV 密码**：登录网盘用，交给网盘验证身份。
- **独立同步口令**：给观策AI 加密远端文件用，至少12位；它不会上传到远端，也不会进入项目导出。

两个都要保存好，但作用不同。建议 WebDAV 使用网盘的“应用密码”，同步口令用“生成”按钮生成并保存到密码管理器。
