# 山东企业模拟案例验收（0.6.2）

2026-10-31，新增 5 家山东企业模拟案例，覆盖智能家电、啤酒、商用车动力、滋补健康和宠物食品。目标不是伪造企业真实效果，而是用可追溯的模拟数据检验观策AI从“资料收集”到“研判、方案、审批、复盘、历史回测、企业适配性”的完整过程。

## 案例

| 企业 | 行业 | 模拟预算 | 过程重点 |
|---|---|---:|---|
| 海尔智家 | 智能家电/全屋智能 | 120 万 | 一站式交付、旧房轻改造、门店承接 |
| 青岛啤酒 | 啤酒/高端饮品 | 80 万 | 夜经济餐饮、终端政策、高端系列认知 |
| 潍柴动力 | 商用车动力/装备 | 60 万 | TCO、服务网络、经销商赋能 |
| 东阿阿胶 | 滋补健康 | 50 万 | 即食化、功效合规、礼品与私域 |
| 乖宝宠物 | 宠物食品 | 40 万 | 成分透明、适口性、复购与宠物店 |

## 交付内容

- 每家企业一份不少于 1 万中文字符的过程性报告，含封面、信号结构、预算、计划 vs 实际、历史基线、可信度图。
- 每家企业一份可导入的 `AppData` JSON 项目。
- 信号 CSV、渠道 CSV、`cases.json` 汇总。
- `methodology.md` 方法、`credibility-summary.md` 横向对比、`iteration-log.md` 迭代记录。

## 过程设计

1. 明确企业公开资料与模拟数据边界。
2. 建立来源清单与采集时间线。
3. 生成消费者/竞品/行业模拟信号，标注状态与相关性。
4. 归纳主题、机会与风险。
5. 设计 A/B 方案，校验预算并生成审批快照。
6. 录入模拟渠道数据，计算 CTR、CPC、线索成本、线索完成率。
7. 与历史模拟基线对比，计算 MAPE 与可信度。
8. 以模拟企业市场负责人视角评估战略契合、可执行性、风险和数据可信度。
9. 输出产品迭代建议。

## 可信度

综合可信度 = 100 ×（0.25×数据完整性 + 0.20×证据核实率 + 0.15×来源多样性 + 0.15×历史基线强度 + 0.15×偏差拟合度 + 0.10×非模型依赖）。

5 个案例的可信度在 69.8–86.2 之间，说明结果可以支持小范围试点，但不能直接代替企业真实预算决策。B2B 案例线索量小、决策链长，可信度更依赖服务网络和真实样本；快消/宠物案例渠道数据更完整，可信度相对更高。

## 应用内案例库

设置新增“模拟案例库”标签：

- 列出 5 个案例的行业、预算、线索、可信度、满意度与适配性。
- “导入为演示项目”将案例写入本机 SQLite，切换后可在四个页面查看。
- 案例文件随安装包放在 `dist/simulations`，不依赖网络。
- CSP 从 `connect-src 'none'` 调整为 `'self'`，仅允许同源读取案例文件。

## 边界

- 所有消费者语句、竞品观察、渠道数据、复盘结果和满意度均为模拟。
- 企业名称和业务方向来自公开资料，但不引用未核实财务数字，不代表企业真实意见。
- 报告不能作为企业真实广告效果或经营结论；企业真实使用前必须替换真实数据并完成合规复核。
